# 数据库造数工具 - Navicat 风格界面

这是数据库造数工具的新版本前端界面，采用类似 Navicat 的布局风格。

## 功能特点

- **左右分栏布局**：左侧树形导航，右侧详情面板
- **完整的层级结构**：连接 → 数据库 → 表 → 字段/索引
- **动态详情显示**：根据选中的节点类型显示相应的详细信息
- **连接管理**：支持新建、编辑、测试数据库连接
- **表结构查看**：支持查看表结构、字段信息等

## 安装和运行

### 安装依赖

```bash
cd web/web-v2
npm install
```

### 开发模式

```bash
npm run dev
```

界面将在 `http://localhost:5174` 启动（与原有界面端口不同，避免冲突）

### 构建

```bash
npm run build
```

## 主要组件说明

### DatabaseTree（树形导航）

- 显示所有数据库连接
- 支持懒加载：点击节点时动态加载子节点
- 支持搜索过滤
- 显示连接状态、数据库类型等信息

### DetailPanel（详情面板）

根据选中的节点类型显示不同的详情：

- **连接节点**：显示连接信息、数据库数量等
- **数据库节点**：显示数据库信息、表数量等
- **表节点**：显示表信息、字段列表、数据行数等
- **字段节点**：显示字段详细信息、类型、约束等

### ConnectionDialog（连接对话框）

- 支持多种数据库类型（PostgreSQL、MySQL、MariaDB、达梦、SQLite、SQL Server、Oracle）
- 连接测试功能
- 表单验证

## 与原有界面的区别

1. **布局方式**：采用左右分栏布局，类似 Navicat
2. **导航方式**：使用树形结构，更直观
3. **详情展示**：右侧面板根据选中项动态显示详情
4. **独立运行**：新界面在独立目录，不影响原有界面
